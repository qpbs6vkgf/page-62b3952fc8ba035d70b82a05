客户端选择（重点）

YaHaHa 通过标准订阅链接对接主流客户端。请先根据操作系统选择应用，再将订阅地址粘贴或二维码导入。本页不托管安装包，请使用各客户端官方渠道获取，以确保签名与更新通道正常。

Windows

常用 Clash Verge、v2rayN、sing-box 图形客户端。下载安装后选择「订阅」或「从 URL 导入」，粘贴 YaHaHa 订阅地址并更新节点。

macOS

可选 ClashX Meta、Surge、Stash。macOS 用户注意授予网络扩展与系统代理权限，导入后开启系统代理或 TUN 模式。

Android

推荐 Clash Meta for Android、v2rayNG。从官方发布页或可靠应用市场安装，导入订阅后可设置分应用代理。

iOS

Shadowrocket、Quantumult X、Stash 为常见选择。需在对应商店获取，导入订阅后配置规则与 DNS，避免全局误伤国内应用。

Linux 与路由器

可使用 clash / mihomo、sing-box 或 OpenWrt 插件。团队用户可将订阅用于网关，实现多设备共享并配合定制路由。

导入成功后，优先选择延迟较低、负载正常的节点。若播放或游戏异常，可更换解锁或 IPLC 标注线路，并确认客户端规则未过期。

操作说明

从了解到连接的五步

  1. 在本页对比基础版、旗舰版与团队版，确认流量、设备数与是否需要 IPLC 或全量流媒体解锁。
  2. 通过 YaHaHa 官方账户完成订阅（本页仅展示套餐结构，支付与开通在账户中心进行）。
  3. 复制专属订阅链接，或按账户提示获取二维码。
  4. 在「客户端选择」中按系统找到对应官方客户端，打开导入入口粘贴链接并更新。
  5. 选择节点连接，检查延迟；需要时开启规则模式，仅对境外域名走代理。

日常维护

定期在客户端内更新订阅，避免节点列表过期。流量将尽时升级套餐或等待周期重置。遇到证书或系统代理异常，可重启客户端或切换 TUN / 系统代理模式。团队版如需定制分流，将需求提交给专属客户经理。

常见问题

YaHaHa 和普通 VPN、机场有什么关系？

YaHaHa 以机场订阅方式提供节点与流量，用户使用自选客户端连接。它同时覆盖网络加速、流媒体访问与游戏线路优化。品牌名称为 YaHaHa，本页为官网信息与客户端指引，不重复叠加后缀。

如何下载客户端才算安全？

请从各客户端项目官方站点、GitHub Release 或系统应用商店获取。YaHaHa 不在本页提供安装包，避免仿冒。导入时只使用您账户内的订阅 URL，不要把链接发给他人。

三个套餐该怎么选？

轻度使用、设备少选基础版（100GB / 3 设备）。需要原生流媒体、游戏 IPLC 与优先支持选旗舰版（300GB / 5 设备）。多成员、高流量或要定制路由选团队版（1000GB / 20 设备）。年付价格已在各套餐标明。

设备数超限会怎样？

同时在线超过套餐上限时，新设备可能无法连接或旧会话被挤下。可先在客户端登出闲置设备，或升级到旗舰版、团队版。路由器共享会占用设备配额，请按套餐规划。

流媒体缓冲或游戏掉线如何处理？

先更新订阅并更换解锁节点或 IPLC 游戏节点，关闭可能冲突的规则。检查本地 DNS 与系统时间。旗舰版工单为优先通道，团队版可联系客户经理协助排查线路。

是否提供退款或流量结转？

具体退订、未用流量是否结转以您订阅时的官方条款为准。本页不替代合同文本。建议先按月体验再年付，并关注流量使用曲线以免浪费。
